# Contenus éditables

Un fichier JSON par bloc de contenu (`services.json`, `avis.json`,
`horaires.json`, `tarifs.json`, `zones.json`…), lu par les composants Astro.

Objectif : le client modifie ses textes, ses prix et ses horaires **sans
toucher au code**. Aucun contenu en dur dans les `.astro` dès qu'il est
susceptible de changer.

Les fichiers arrivent en Phase 4, une fois le brief et la DA validés.
